# Release Notes


## [Unreleased]

### Added
 - Added support for finding Person by username and employee_code in PersonService::find()
 - Integrated PersonUserType associations into PersonService profile output
 - added project documentation

### Changed
 - PersonService::get() now returns a clean short profile array (display_name, employee_code, user_id, username, primary_mobile/email, user_types, contacts, addresses, banking, media)

### Feature
 - Completely rewrote PersonService with smart find/search/get/upsert methods supporting person_code, PAN, Aadhaar, mobile, email, username and employee_code lookup
 - Created PersonUserTypeService with assign, setPrimary, remove, getUserTypes, getPrimary, getSummary, syncFromUsers and syncFromPersons methods
 - Introduced PersonUserType system (xlr8_admin_person_user_types) to support multiple associations (Emp/Cust/DSA/etc.) per Person with primary flag

### Fixed
 - Fixed cleanPhone() method – previous ltrim(&#039;91&#039;) was incorrectly stripping leading 9, breaking all mobile searches
